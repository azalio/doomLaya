# Laya Doom MAP03

Laya прошла FreeDoom MAP03 и сыграла три секунды на MAP04.
Модель получает текстовое состояние игры и выбирает действие, цель, оружие
и движение в бою. Исполнитель строит маршрут, целится и нажимает кнопки
по её команде.

## Проверенный результат

Прогон 27 сентября 2026: macOS/MPS, seed 54, skill 3, 35 тиков/с.
Выход с MAP03 — на 819,914 с, после четырёх смертей. Полная запись —
822,943 с; на MAP04 записаны 106 кадров. Перед выходом у игрока было
63 HP, 84 брони и все три ключа.

`experiment_valid=true`, `level_completed=true`: проверены 28 803 кадра
и 1595 принятых решений. Общая проверка качества не пройдена (`passed=false`):
максимальная неподвижность — 141,83 с, время без нового района — 159,29 с.
Это один успешный прогон на карте, использованной при разработке.
Устойчивость на других seed и прохождение MAP01/MAP02 этим комплектом
не проверены. Возможны зацикливание, ошибки выбора ресурсов и смерть игрока.

Медиана HTTP-задержки полного решения с RTT — 342,52 мс, p90 — 406,70 мс.
Минимальная задержка применения — 16 тиков; фактическая медиана — 457,143 мс.
Внешних API-вызовов не было; стоимость локального обучения и вычислений
не оценивалась. Jev на MAP03 с этой конфигурацией не проверялась.

## Состав комплекта

| Вопрос | Каталог |
|---|---|
| Огонь во время движения и базовые головы | `laya-map2-explicit-v2` |
| Действие | `laya-map3-combat-priority-v1` |
| Предмет | `laya-map3-item-category-v1` |
| Очередь противников | `laya-map3-ranked-enemy-v1` |
| Оружие | `laya-map3-compact-weapon-v1` |
| Движение в бою | `laya-map3-compact-movement-v1` |
| Осмотр | `laya-map3-look-floor-v2` |
| Механизм | `laya-map3-switch-route-v1` |

Это восемь полных checkpoint, около 12,6 GiB вместе. Сервер использует один
общий энкодер после проверки побитового совпадения его весов. Голова зависит
от имени вопроса. Преобразования входа и составные ответы зафиксированы
в `question-heads.json`; варианты действий выбирает модель.

Хеш комплекта:
`88f90e1bee336ee8f188cc5d62cf691746212fa7e8c81b85a1a0e2db1cf359d5`.
Для проверки файлов используйте `SHA256SUMS`.

## Обучение

Головы дообучены по записанным игровым состояниям, меткам офлайн-эксперта
и синтетическим примерам. Энкодер заморожен. Это обучение с учителем
и имитация решений эксперта; оптимизации по игровой награде и RL нет.
Эксперт не управляет игроком во время итогового прогона.

Последняя голова предметов обучалась на 3113 примерах, проверялась на 1773.
Из них 768 и 192 соответственно — синтетические. Четыре эпохи, LR 1e-4,
примеры выбора здоровья имеют удвоенный вес; сохранена третья эпоха.
Совпадение с разметкой — 1241/1773, подтверждено через API.
Проверочная выборка использовалась при разработке: её ошибки повлияли
на формат входа и новые примеры. Это не независимая оценка переноса.

[Данные, этапы и команды обучения](https://github.com/azalio/doomLaya/blob/v0.3.0/docs/MAP03.md).
Конфигурации, лучшая эпоха и метрики входят в каждый checkpoint.
База: `convaiinnovations/laya/typed-decisions`, ревизия
`1c5edc17a7acd8701df6fc341c0d179f1c62c982`; исходники Laya —
`42626c348753fbb17572a813127df2278a1ec527`.
Лицензия Apache-2.0, атрибуция — в `NOTICE`.

## Запуск

Установите doomLaya v0.3.0 и зависимости по
[инструкции MAP03](https://github.com/azalio/doomLaya/blob/v0.3.0/docs/MAP03.md).
Из корня репозитория:

```bash
.venv/bin/hf download azalio/laya-doom-map03 --revision v0.3.0 \
  --local-dir checkpoints/laya-doom-map03
(cd checkpoints/laya-doom-map03 && shasum -a 256 -c SHA256SUMS)
```

Команды сервера и игры приведены в той же инструкции. Нужен включённый
в doomLaya патч ViZDoom для MAP03. Исполнитель знает геометрию карты,
ключи, выход, механизмы и координаты оружия. Модель загружается сервером
doomLaya, а не `transformers.pipeline`.
