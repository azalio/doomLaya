## Повторить проверку

Установите окружение и запустите сервер v0.3.0 на порту 8002 по
[инструкции MAP03](MAP03.md). Во втором терминале, из корня репозитория:

```bash
regression_map() {
  caffeinate -i .venv/bin/python agent.py --model doom-adapted \
    --endpoint http://127.0.0.1:8002/predict --decision-format committed \
    --question-schedule conditional --interval 0.5 \
    --minimum-decision-delay-ticks 16 \
    --explicit-actions --explicit-movement --movement-facts --movement-obstacle-facts \
    --refresh-attack-target --enemy-visibility-facts --enemy-commitment-facts \
    --enemy-sequences --look-gate --floor-hazard-facts --attack-turn-rate 9 \
    --weapon-sensor --map-weapons --reachable-items --mechanism-facts \
    --combat-during-navigation --pickup-recent-targets --inventory-events --ammo-events \
    --mask-unreachable-items --map "$1" --skill 3 --seed "$2" --seconds "$3" \
    --record auto --stop-after-level --tag "$4"
}
regression_map MAP01 48 180 v030-regression-map01-seed48
regression_map MAP02 54 1800 v030-regression-map02-seed54
```

На Linux уберите `caffeinate -i` и используйте серверный `--device auto`.
Проверка выполнена на macOS/MPS; результат на других устройствах не проверен.
Путь к каждой записи появится в строке `RUN`. После завершения обеих игр:

```bash
.venv/bin/python -m tools.verify_run runs/<каталог-RUN>
```

Код возврата 1 означает, что хотя бы один критерий не выполнен.
В `verification.json` смотрите отдельно `experiment_valid`, `level_completed`,
`authority.pass` и общий `passed`. Корректная запись не означает прохождение.

## Что установлено

Обе карты не пройдены в прежних лимитах. Ошибок API и нарушений исполнения
решений нет. Повторный выбор аптечки и смена целей записаны в ответах модели;
аудит подтверждает, что контроллер применял эти ответы.

Причина регрессии пока не изолирована: по сравнению с v0.2.0 изменились
веса, формат вопросов и параметры исполнения. Для исправления нужно
отдельно проверить выбор полезных предметов и удержание цели до её
достижения, затем повторить MAP01, MAP02 и MAP03 одним комплектом.

Видео и полные журналы остаются в локальном каталоге `runs/` и исключены
из Git. Указанные пути доступны на машине, где выполнена проверка; на GitHub
эти записи не загружены.
